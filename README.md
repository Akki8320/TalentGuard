# TalentGuard: AI-Driven Retention Platform

> **"Protecting your most valuable assets through data science."**

[![Live Demo](https://img.shields.io/badge/demo-online-brightgreen)](https://akki8320.github.io/TalentGuard/)

TalentGuardは、データサイエンスを用いてハイパフォーマーの離職を未然に防ぎ、企業の持続的な成長を支援するAIプラットフォームです。

## 🚀 Overview
多くの企業において、成果の25%を創出する「エース人材」の流出は、単なる欠員以上の経済損失をもたらします。
TalentGuardは、東京大学GCIでの知見と、サンフランシスコのスタートアップ・エコシステムで培ったビジネス視点を融合させ、「予測するだけでなく、介入を成功させる」ことに特化したソリューションを提供します。

## ✨ Key Features
- **High-Precision Prediction**: AUC 0.84を記録した高精度モデル。離職が表面化する平均2ヶ月前にリスクを特定。
- **What-If Simulator**: 給与調整や残業削減が離職リスクに与える影響をリアルタイムにシミュレーション。
- **Tactical 1-on-1 Playbook**: 各個人の離職要因（報酬・負荷・不満）に合わせた最適な対話シナリオを自動生成。
- **Financial Impact Visualizer**: 離職防止による具体的なROI（投資対効果）を可視化。

## 📊 Multi-Stage Intervention
1. **早期検知 (3ヶ月前〜)**: 「不公平指数」等の独自指標に基づき、組織全体のエンゲージメント低下を早期に捕捉。
2. **直接介入 (2ヶ月前)**: AIが特定したゴールデンタイムに、具体的なリテンション施策を実行。
